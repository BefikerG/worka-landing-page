# WORKA

WORKA is a local-first work-location discovery experience for finding the right place to work, study, create, meet, and focus.

This repository contains the responsive landing page prototype for the WORKA product vision, starting in Addis Ababa and designed to scale to cities everywhere.

## Highlights

- Editorial visual direction built around discovery, movement, and calm
- Responsive layouts for desktop, tablet, and mobile
- Interactive map-inspired hero and place discovery interface
- Workability scoring concept with Wi-Fi, noise, power, and comfort signals
- Work-mode selector for deep work, casual work, creative sessions, study, and meetings
- Addis-first city storytelling and community contribution sections
- Functional early-access waitlist modal
- TypeScript, React, and Vite with no unnecessary runtime dependencies

## Local development

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, typically `http://localhost:5173`.

## Commands

```bash
npm run dev      # Start the development server
npm run build    # Type-check and create a production build
npm run lint     # Run Oxlint
npm run preview  # Preview the production build locally
```

## Notes

The current place data and imagery are intentionally fictional/prototype content. Replace the Unsplash image URLs and conceptual location data with approved WORKA assets and production APIs before launch.
